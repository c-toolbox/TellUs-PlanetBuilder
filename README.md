# Tellus Demo

Web based demo for Tellus project.

## Get started

### Prerequisites

- Git
- Node 20+

### Steps

1. Clone the repository
2. `npm install`
3. `npm run dev`

### Building

1. `npm run build`
2. Build goes to `/dist` directory

## System requirements

| System  | Description                                                                          |
| ------- | ------------------------------------------------------------------------------------ |
| Web     | A modern up-to-date web browser                                                      |
| Windows | Microsoft Edge 89+ and [WebView2](https://go.microsoft.com/fwlink/p/?LinkId=2124703) |
| MacOS   | Safari 15 or newer                                                                   |
| Linux   | WebKitGTK installed                                                                  |
